# Digital Home & Office

Mobile-first technology storefront for Digital Home & Office, Eastgate Market, Harare.

## Deployment

- Vite + React
- Run `npm install`
- Run `npm run build`
- Deploy the generated `dist/` folder to Cloudflare Pages
- No Base44 dependency
